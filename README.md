# Who Taunted?

Addon project for World of Warcraft.

- <https://www.curseforge.com/wow/addons/who-taunted>
- <https://www.wowinterface.com/downloads/info14842-WhoTaunted.html>
- <https://addons.wago.io/addons/who-taunted>

## About

Tracks player taunts and displays who they taunted, what ability they used to taunt, and if it failed in some way.

> [!WARNING]
>
> ## Midnight Compatibility
>
> **Who Taunted does not support WoW Midnight (12.0+).** Blizzard's combat API restrictions prevent addons from accessing real-time combat log data which is essential for this addon to function. See [Issue #77](https://github.com/Davie3/who-taunted/issues/77) for more details and my personal thoughts.
>
> See Blizzard's blog post: [Combat Philosophy and Addon Disarmament in Midnight](https://worldofwarcraft.blizzard.com/en-us/news/24246290)
>
> **Supported:**
>
> - WoW Classic (Vanilla, TBC, Wrath, Mists)
>
> **Not Supported:**
>
> - Midnight (12.0+) and future retail expansions unless Blizzard makes any changes
